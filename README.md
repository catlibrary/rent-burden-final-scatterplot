# Poverty vs Income Scatterplot

## Overview
This project is an interactive Shiny-based R Markdown visualization comparing median household income and poverty rate across U.S. states using 2023 ACS data.

## My Contribution
I created this interactive scatterplot as part of a group dashboard project for an advanced data visualization course. The graph was designed to allow users to highlight a selected state and compare it against national patterns.

## Tools Used
- R
- R Markdown
- Shiny
- tidycensus
- tidyverse
- ggplot2

This visualization was originally created to be incorporated into a larger group dashboard. This repository highlights my individual contribution. Because it is a Shiny-based document, it is shared here as code rather than a live GitHub Pages site.
